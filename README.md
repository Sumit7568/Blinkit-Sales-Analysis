🛒 Blinkit Sales Analysis
📌 Project Overview

This project analyzes Blinkit sales data to understand customer purchasing behavior, product performance, and overall sales trends.

🎯 Objective

To identify key drivers of sales and support data-driven decisions for improving revenue and customer engagement.

📊 Key Analysis

Sales trends by product category and time

Customer purchase patterns

Revenue contribution analysis

High-performing products and segments

🛠 Tools & Technologies

Python

SQL

Data Analysis & Visualization

📈 Outcome

The analysis delivers actionable insights to optimize product strategy, improve sales performance, and enhance business decision-making.
